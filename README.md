# TimeTracker

TimeTracker - desktop-приложение на WinUI 3 (Windows) для мониторинга экранного времени, анализа активности и формирования полезных рекомендаций по использованию компьютера.

## Описание

Проект собирает данные об активных окнах, сохраняет сессии использования в локальную базу SQLite и отображает статистику в удобном интерфейсе по страницам.

Архитектура построена по MVVM и разделена на логические модули:
- `Models` - сущности данных (приложения, категории, сессии, дневная статистика);
- `Services` - бизнес-логика, расчеты, очистка данных, AI-инсайты;
- `Data` - работа с SQLite и инициализация структуры БД;
- `Monitoring` - сбор активности пользователя через системные API;
- `ViewModels` - подготовка данных и команды для UI;
- `Views` - XAML-страницы интерфейса.

## Стек

## Возможности

- Отслеживание активности пользователя:
  - фиксация активного приложения и длительности сессий;
  - сохранение сырых событий в `UsageSessions`;
  - фоновая очистка устаревших данных.

- Главная (`Dashboard`):
  - карточки ключевых метрик за день;
  - недельный график активности;
  - график активности выбранного приложения;
  - список используемых приложений и блок с AI-советами.

- Категории (`Categories`):
  - аналитика по категориям приложений (сегодня/неделя/месяц);
  - топ приложений внутри каждой категории;
  - сравнение и доля категории в общем времени.

- Приложения (`Applications`):
  - список обнаруженных приложений;
  - назначение категории для каждого приложения;
  - сохранение изменений классификации.

- Настройки (`Settings`):
  - дневной лимит использования ПК;
  - API-ключ для AI-функций;
  - включение/выключение автозапуска.

## База данных

Локальная база SQLite содержит:
- `Categories` - справочник категорий;
- `Applications` - справочник приложений и их категорий;
- `UsageSessions` - сырые сессии активности;
- `DailyAppStats` - агрегированная статистика по дням.

Поддерживается хранение данных с ориентацией на длительный период (6-12 месяцев) с автоматической очисткой.
